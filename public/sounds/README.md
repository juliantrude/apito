# Sounds

Eigene Aufnahmen hier ablegen. Fehlt eine Datei, erzeugt die App einen
synthetischen Platzhalter. Erlaubte Endungen: `.wav`, `.mp3`, `.ogg`.

| Datei            | Wann                          |
| ---------------- | ----------------------------- |
| `groove`         | Klick auf jedem Groove-Schlag |
| `accent`         | Klick auf der Eins im Groove  |
| `break`          | Klick auf jedem Schlag im Break |
| `count-whistle`  | Pfiff auf jedem Zählschlag    |
| `double-whistle` | Doppelpfiff zur Ankündigung   |

Tipps: Den Ton genau am Dateianfang beginnen lassen (keine Stille davor),
sonst klingt alles verzögert. Klicks kurz halten, unter 100 ms.
